Справка

Как пользоваться системой распознавания языка (лабораторная работа, вариант 25: французский / английский).

1. Как выполнить анализ

На странице «Анализ» перетащите HTML-документы в область загрузки или нажмите на неё и выберите файлы. Можно загрузить сразу несколько документов — система обработает их последовательно и покажет сводную таблицу результатов. Для запуска нажмите кнопку «Определить язык».

Каждый документ должен содержать связный текст на одном из языков: французском или английском. Оптимальный объём — около одной страницы A4 (2–4 тысячи знаков). При меньшем объёме вероятность ошибки растёт, поскольку сужается статистическая база сравнения.

2. Оценка точности

Если имя файла начинается с префикса FR_ или EN_, система считает язык известным и показывает колонку с проверкой («верно»/«ошибка»), а также рассчитывает точность каждого метода и итогового решения. Документы без префикса распознаются обычным образом, но в подсчёт точности не включаются.

3. Методы распознавания

Метод частотных слов. Для каждого языка заранее построен поисковый образ — 200 самых частых слов с вероятностями. Документ сравнивается пословно: слова, найденные в образе, получают свои вероятности, отсутствующие — штрафную минимальную вероятность. Побеждает язык с максимальной суммарной лог-вероятностью (в расчёте на 1000 слов).

Алфавитный метод. Профиль языка — распределение частот букв (включая французские é, è, à, ç, œ и другие). Строится такое же распределение документа и вычисляется расстояние между профилями (сумма модулей разностей частот). Побеждает минимальное расстояние.

Нейросетевой метод. Многослойный перцептрон (scikit-learn MLPClassifier) обучен на фрагментах тренировочного корпуса. Признаки документа — частоты 43 букв и частоты {{ meta.word_list_size or 60 }} частотных слов. Сеть возвращает язык и вероятность класса.

4. Итоговое решение

Итоговый язык документа определяется голосованием большинства по трём методам: если хотя бы два метода указали один язык, он и считается результатом. Такая схема устойчива к одиночным ошибкам отдельных методов. Каждый метод также выводит свою меру уверенности: лог-оценку, расстояние или вероятность.

5. Сохранение и печать

На странице результатов доступны кнопка «Сохранить отчёт (TXT)» — выгрузка полного отчёта в текстовый файл — и кнопка «Печать», которая открывает стандартный диалог печати браузера с подготовленной печатной версией таблицы. Ссылка на имени документа открывает исходный файл; ссылка «текст» — извлечённый из документа текст.

6. Профили языков

Профили построены по тренировочному корпусу из Википедии: {% if meta.train_chars %} французский — {{ (meta.train_chars.fr // 1024) }} КБ текста, английский — {{ (meta.train_chars.en // 1024) }} КБ. {% else %} ~110 КБ текста на язык. {% endif %} Модели хранятся в папке models/ и могут быть перестроены командой python train.py после пополнения корпуса в папке corpus/train/.

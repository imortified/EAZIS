Помощь

О системе

Информационно-поисковая система «Модуль отбора документов», вариант 25: сфера применения — локальная вычислительная сеть (ЛВС), стратегия поиска — логическая, язык коллекции и запросов — русский.

Система автоматически строит поисковые образы документов: выполняет токенизацию, отбрасывает незначимые слова, приводит словоформы к основам и рассчитывает вес каждого термина по формуле TF-IDF: вес Ai = Qi·Bi, где Qi — частота основы в документе, Bi = log(N / Pi) — инверсная частота, N — число документов базы, Pi — число документов с термином i.

Как искать

ПриёмДействие
Несколько словПо умолчанию документ должен содержать все слова (стратегия с отказами).
AND / ИПересечение: локальная AND сеть — только документы с обоими словами.
OR / ИЛИОбъединение: wifi OR bluetooth — документы хотя бы с одним словом.
NOT / НЕИсключение: сеть NOT wifi — документы о сетях без слова wifi.
( )Группировка: (сеть OR сервер) NOT безопасность.
ДатыПоля «Дата с … по …» ограничивают выдачу датой добавления документа.

Словоформы сводятся к основе: запрос «сетей» найдёт и «сеть», и «сетях». Если слова нет в словаре индекса, система сообщит об этом и предложит исправление (см. ниже) — это нормальное поведение логической стратегии (отказ по отсутствующему термину).

Исправление опечаток

Если слова запроса нет в словаре индекса, модуль исправления опечаток подбирает ближайший по написанию термин: «компютер» → «компьютер», «безопастность» → «безопасность». Сравнение выполняется по расстоянию Дамерау–Левенштейна, которое учитывает вставку, удаление, замену символа и перестановку двух соседних букв; допустимое число правок зависит от длины слова.

Модуль распознаёт и неверную раскладку клавиатуры: запрос rjvgknth превращается в «компьютер». Поиск автоматически не изменяется: система показывает подсказку «возможно, вы имели в виду …» со ссылкой — повторный поиск выполняется только по щелчку пользователя.

Документы и модуль отбора

Документы можно добавить тремя способами: вручную (заголовок и текст), загрузкой файла .txt/.md и через модуль отбора документов — он рекурсивно обходит указанную папку (в том числе общий сетевой каталог ЛВС, например \\server\share), отбирает текстовые файлы, определяет кодировку, отсекает дубликаты и индексирует отобранное.

Заголовком при импорте файла становится первая непустая строка текста. Дубликаты определяются по контрольной сумме текста.
